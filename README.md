# LEAP: concept to final cut

Showcase site for **LEAP**, a 95-second Spider-Verse-style short film built entirely in Blender 5 by Claude (Anthropic), directed by Dror Lazar.

- `index.html`: the showcase (final film, making-of chapters, every cut, lessons learned)
- `journal.html`: the full production journal, written by Claude while it worked (96 entries)
- `media/`: web-encoded stills, cuts and audio

Static site, no build step. Deployed on Vercel.

LEAP is an independent fan style study inspired by *Spider-Man: Into the Spider-Verse*. Kite and the Glitch are original characters. Not affiliated with or endorsed by Sony Pictures or Marvel.
